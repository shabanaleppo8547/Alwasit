# 👑 مركز الوسيط

تطبيق أندرويد (Flutter) لمواعيد محاضرات المركز، مع خادم صغير على Vercel يحفظ البيانات في مكان واحد للطلاب والإدارة.

```
api/        الخادم: /api/schedule للطلاب، و /api/admin للإدارة
lib/        منطق الخادم: التخزين، والصلاحيات، والتحقق، والبيانات الأولى (seed.js)
app/        تطبيق Flutter
api_url.txt عنوان الخادم الذي يُبنى عليه التطبيق
.github/    بناء ملف APK تلقائيًا عند كل تعديل
```

## إعداد الخادم على Vercel (مرة واحدة، من الموبايل)

1. افتح **vercel.com/new**، واختر المستودع **alwasit**، واضغط **Import** ثم **Deploy**.
2. من صفحة المشروع: **Storage** ← **Create Database** ← **Upstash for Redis** ← الخطة المجانية ← **Create**، ثم **Connect** للمشروع.
3. **Settings** ← **Environment Variables**: أضف `ADMIN_PASSWORD` وقيمته كلمة مرور الإدارة (6 أحرف على الأقل)، ثم **Save**.
4. **Deployments** ← النقاط الثلاث بجانب آخر نشر ← **Redeploy**.
5. افتح عنوان المشروع، مثل `alwasit.vercel.app`. يجب أن تظهر رسالة «✅ يعمل».

## تحميل التطبيق

بعد كل تعديل على المستودع، يبني GitHub ملف `alwasit.apk` تلقائيًا، وينشره في صفحة **Releases** للمستودع.

## لماذا Vercel؟

موقع الطلاب الحالي مستضاف على Vercel ويعمل في سوريا دون VPN، فالتطبيق يتصل بنفس الاستضافة. قاعدة Redis يتصل بها الخادم فقط، ولا يتصل بها هاتف الطالب مباشرة.

## الأمان

- القراءة مسموحة للجميع، أما أي تعديل فيحتاج كلمة مرور الإدارة. والتحقق يتم على الخادم نفسه، لا داخل التطبيق.
- بعد 10 محاولات دخول خاطئة يُوقف الدخول ربع ساعة.
- كل تعديل يحفظ النسخة السابقة من البيانات (آخر 50 نسخة)، للاسترجاع عند الخطأ.
- تغيير `ADMIN_PASSWORD` في Vercel يُخرج كل الأجهزة من لوحة الإدارة.
