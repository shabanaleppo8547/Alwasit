# خطة التطوير: الميزات المتقدمة

البنية الحالية جاهزة لهذه المراحل دون إعادة بناء. هذا ما سنضيفه في كل مرحلة، وأين.

## 1. حماية الفيديو الحقيقية (DRM)

**الوضع الحالي:** بث عبر الخادم بعد التحقق، دون كشف المصدر، مع علامة مائية وFLAG_SECURE في تطبيق Android. هذا يمنع مشاركة الروابط، لكنه لا يمنع من يملك اشتراكًا من التقاط تدفق الفيديو من المتصفح.

**المرحلة التالية:**
- رفع الفيديوهات إلى مزوّد بث يدعم **Widevine** (Android/Chrome) و**FairPlay** (iOS/Safari)، مثل Bunny Stream (MediaCage) أو VdoCipher أو Mux أو Cloudflare Stream. نختار حسب السعر والوصول من سوريا.
- `src/server/video.ts` يصبح مسؤولًا عن إصدار **رابط تشغيل موقّع قصير العمر** و**رمز ترخيص** مرتبط بالطالب، بدل تمرير الملف.
- `video_ref` يأخذ صيغة مثل `bunny:<videoId>`، ولا تحتاج قاعدة البيانات أي تغيير.
- المشغّل في الويب يصبح Shaka Player أو مشغّل المزوّد، مع EME.
- البث عبر الخادم الحالي يستهلك عرض نطاق Vercel، فمع المحتوى الحقيقي يجب الانتقال إلى مزوّد بث.

## 2. تنزيل المحاضرات مشفّرة + العمل دون إنترنت 7 أيام

يحتاج **كودًا أصليًا (Native)**، لأن المتصفح لا يدعم تراخيص DRM دائمة للتشغيل دون اتصال.

- **Android:** إضافة Capacitor بلغة Kotlin تستخدم **Media3/ExoPlayer DownloadManager** مع **ترخيص Widevine offline** (`OfflineLicenseHelper`). الملف المحمّل مشفّر ولا يعمل خارج التطبيق.
- **iOS:** `AVAssetDownloadURLSession` مع **FairPlay persistent keys**.
- **مدة 7 أيام:** الخادم يصدر الترخيص بمدة `rental/playback duration` = 7 أيام. عند كل اتصال يجدّد التطبيق الترخيص إن كان الاشتراك ما زال ساريًا، وعند انتهاء الاشتراك يرفض الخادم التجديد.
- **في قاعدة البيانات (مرحلة لاحقة):** جدول `devices` (ربط الحساب بعدد محدود من الأجهزة) وجدول `offline_licenses` (الجهاز، المحاضرة، تاريخ الإصدار، تاريخ آخر تجديد).
- **حذف المحاضرات المحمّلة:** يُحذف الملف وترخيصه من الجهاز فقط، ويبقى الاشتراك في الخادم، فيمكن إعادة التنزيل ما دامت الصلاحية سارية.

## 3. ميزات تحتاج تنفيذًا أصليًا (لا تكفي تقنيات الويب)

| الميزة | Android | iOS |
|---|---|---|
| منع لقطات/تسجيل الشاشة | ✅ مطبّق (FLAG_SECURE) | كشف التسجيل (`UIScreen.isCaptured`) وإخفاء المحتوى |
| تشغيل DRM | Media3 + Widevine | AVPlayer + FairPlay |
| تنزيل مشفّر + 7 أيام دون اتصال | Media3 Downloads + ترخيص offline | AVAssetDownloadURLSession + persistent keys |
| ربط الحساب بالجهاز | معرّف جهاز + Play Integrity | App Attest |
| الإشعارات | FCM | APNs |

## 4. المساعد الذكي

- واجهة محادثة داخل صفحة المادة، مرتبطة بمحتوى المادة (ملخصات، أسئلة شائعة، تمارين).
- يعمل من الخادم فقط (مفتاح الـ API لا يصل للهاتف)، ويُتاح للطلاب المشتركين في المادة، مع حد للاستخدام.

## 5. iOS

نفس مشروع Capacitor (`npx cap add ios`). البناء يحتاج macOS، ويمكن تنفيذه سحابيًا عبر GitHub Actions (`macos-latest`) أو Codemagic، مع حساب Apple Developer (99$ سنويًا) للنشر.

## 6. تحسينات أخرى مخطط لها

- دور **المدرس** (القيمة `teacher` موجودة في قاعدة البيانات): لوحة يرى فيها مواده وطلابه.
- تتبع تقدم المشاهدة لكل محاضرة.
- توثيق البريد الإلكتروني عند التسجيل.
- رفع الفيديو من لوحة الإدارة مباشرة إلى مزوّد البث.
- بوابة دفع عندما تصبح مناسبة.
